# Python Utilities

A small command-line project with a calculator and a distance unit converter. It uses only Python's built-in features.

## Requirements

- Python 3

## Run the project

Open PowerShell in this folder and run:

```powershell
py main.py
```

Choose an option from the menu:

1. **Calculator** — add, subtract, multiply, or divide two numbers.
2. **Unit Converter** — convert kilometers to miles or miles to kilometers.
3. **Exit** — close the program.

## Project files

- `main.py` — displays the menu and starts the selected tool.
- `calculator.py` — calculator logic.
- `converter.py` — distance conversion logic.

## Example

For kilometers to miles, choose `1`, enter `10`, and the program displays approximately `6.21 miles`.
